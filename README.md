# TripTalk

Password-protected group trip planner — meal sign-ups, weather, and day
plans for weekend getaways.

## Stack

- Static frontend (HTML/CSS/vanilla JS) hosted on GitHub Pages
- [Supabase](https://supabase.com) (Postgres + Auth + Row Level Security)
  for the shared group password gate and data storage
